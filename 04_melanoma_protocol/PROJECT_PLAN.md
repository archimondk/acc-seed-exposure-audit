## 2. 种子构建：只依据疾病测量，不依据排名

### 2.1 突变候选与阈值

候选固定为TCGA 2015原始论文列出的13个SMG：`ARID2, BRAF, CDKN2A, DDX3X, IDH1, MAP2K1, NF1, NRAS, PPP6C, PTEN, RAC1, RB1, TP53`。来源为[TCGA原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4580370/)，DOI `10.1016/j.cell.2015.05.044`；本轮核对到13基因段落，不使用按药物结果人工补入的通路成员。该文与本研究使用同一TCGA资源，不称独立发现队列。

只在主队列E/K患者的同一样本MAF中计算复发率，每基因每患者最多一次。纳入`Missense_Mutation, Nonsense_Mutation, Nonstop_Mutation, Splice_Site, Translation_Start_Site, Frame_Shift_Del, Frame_Shift_Ins, In_Frame_Del, In_Frame_Ins`；其余分类不纳入并列频数，未知分类不猜定。过滤规则以固定MAF标注为准，不把每个错义变异都解释为致病。

候选基因同时满足突变患者≥10人且占E/K组≥5%时：G=1，R=min(突变比例/0.20,1)。未满足者G=R=0。无逐位点可检出性证明作为限制保留。

### 2.2 RPPA来源与特征处理

数据为提供者的RPPA z-score；不再进行全表z标准化，也不假称原始绝对蛋白量。

- 对198个特征建立候选清单；主规则只允许单一明确基因注释，多基因抗体不在主分析拆给多个基因。未知/多基因、样本不足、常量或不可检验项均记原因，P=1占位。
- 对其余特征用双侧Mann–Whitney U，固定`method=asymptotic`、连续性校正启用，BH家族固定198项。选入要求q<0.01且两组中位数z差绝对值≥0.5。
- 同基因多个合格抗体：取绝对中位数差最大者；并列按feature名称字典序。保存全部抗体结果、方向及冲突，不把多次抗体测量当独立基因证据。
- L=min(所选绝对中位数差/2,1)；无合格特征L=0。绝对差忽略上/下调方向，仅供无符号网络审计，不支持“抑制该基因即可治疗”的结论。
- 调整敏感性用HC3组别P值另作198项BH，q<0.01且绝对组别系数≥0.5选择，L用绝对系数/2；该效应不是中位数差，两种定义分开命名。

### 2.3 权重与已知靶点防循环规则

沿用现有控制疾病的有效分量：`w_raw = 0.30 G + 0.20 R + 0.10 L`。core_pathway、prognostic_subtype、therapeutic_relevance均为0，因本轮没有预先编码的独立证据，不补主观评分。正权重归一到和为1。

**推荐主臂M0：强制不把BRAF、MAP2K1、MAP2K2放入重启种子。** 这与乳腺癌主臂排除CDK4/CDK6的思路一致，用于避免已知机制靶点直接进入输入。它不删除这些节点、网络边或药物基因关联，也不能消除其邻域的间接信息。

**预定义干预臂M1：恢复上述基因中按疾病规则本来就合格者。** 使用其原始计算权重，不额外赋权或强行补基因；重归一并为M1重建自己的零模型。M0/M1的差别始终全部报告，M1不能在结果好时被升格为主臂。若无合格被排除基因，两臂相同，记录无需重复。

按第2.4节，BRAF几乎必然合格，而它在关联网络中只连到Dacarbazine和Tioguanine，不连任何BRAF/MEK药物。因此M1的性质与原稿RB1干预相同：直接暴露药物在冻结前已知（Dacarbazine、Tioguanine），六个BRAF/MEK药物对它而言都是未暴露药物，正好承担ribociclib在RB1干预中的角色。Dacarbazine是获批用于黑色素瘤的化疗药，但它与BRAF的关联来自NCI-60表达—药效相关，与BRAF机制无关。若M1中Dacarbazine上升，只能解读为种子暴露造成的排名变化，不能解读为对已知疗法的“恢复”。

保留完整`seed_candidates.csv`和`seeds_frozen.csv`，包括不合格项、证据、权重分量、是否在STRING、排除原因。只允许与固定STRING符号精确对应的种子；未映射项单列，不创建仅为使种子上图的虚构孤立节点；在固定图中真实存在但degree=0的节点按原算法处理并报告。此处与旧load_string_graph(required_nodes)可能行为不同，必须写测试及披露。

## 3. 冻结网络、药物与分数定义

- 主药物集合为原网络124种；399个药物关联基因、1304条关联来自既有冻结文件。这些是药物基因组学关联，不是124药物的直接结合靶点图。
- 历史108药物只作集合敏感性；依据原108药物名单，不读取其ACC效力值来选择黑色素瘤结果。
- 使用同一STRING v12全图，combined score≥400，蛋白映射到符号后去自环、按原实现累加重复符号边，edge weight=combined_score/1000。固定节点域为protein.info内所有符号与原399关联基因；不随新种子增删节点。
- 重启概率α=0.40（不是传播概率）；column RWR带原实现dangling mass返回重启分布，L1差<1e-10、最多500次迭代；不收敛即报错，不交付最后一次近似当成功。
- 同时运行`column_minmax`（主）、`column_gene_rank`、`uniform_ratio_gene_rank`、`symmetric_gene_rank`。对全图传播后**先投影到399个关联基因，再归一化**，匹配现有代码；均匀重启基线在同一全图产生。
- 每变体v的背景均值μ_v为原1304条药物—基因边上的归一化基因分数平均，不沿用ACC数值，也不是399个基因的简单平均。
- `C_MEL,v(d) = [sum(g in A_d) r_v(g) + 3 μ_v] / [|A_d|+3]`。在124药内转平均秩百分位`(average_rank-1)/(N-1)`，高分越靠前。Top-k用分数降序、药物名字典序打破并列；同时报告边界并列数量。
- 本例不构建ADRS_comp，不沿用ACC MIPE残差，不把PRISM混入评分。它复用并审计网络模块，不是复现原ACC复合分数的每一项。

## 4. 主要审计指标与统计解释

### 4.1 审计指标

以下指标全部输出；主臂、主归一化、124药为主要描述，不从敏感性里选最好值。

1. **直接重叠基线**：L_count=种子命中数/(|A_d|+3)，L_weight=命中种子归一权重和/(|A_d|+3)；另报告命中比例及关联基因数基线。与C_MEL的Spearman、Top20交集/Jaccard。Spearman用平均秩，常量时NA，不替换成0。
2. **未暴露药物**：种子命中0者的数量、最高百分位及Top25%占位数（124药取前31；108药取前27）。即使有1个未暴露药物进入前四分位，也不能写“未暴露者均无法进入”。
3. **种子/非种子分解**：分别使用A_d∩S和A_d\S计分，k=3和同臂同变体的原μ_v不变；空集合返回μ_v，保留药物。报告非种子评分与主评分的rho、Top20变化、逐药位移，以及无剩余基因的药物。
4. **度/网络位置**：每药关联基因平均degree、strength、PageRank（damping=0.85）及基因集大小与C_MEL的相关；报告C_MEL与零模型z在控制L_count平均秩后的部分Spearman。设计退化、零方差均NA。
5. **成员干预**：M0/M1两臂全部药物的排名和零模型z差；M0全种子LOSO（去1个、余权重重归一），四变体，记录最大/中位绝对位移、位移≥5/≥10数量、Top20变化及直接关联/未关联药物分层。
6. **无伪重复**：药物共享基因、机制和网络位置，不把124药当124个独立生物学重复；上述相关与位移不附未经校准的常规显著性P值，不把药物bootstrap称患者置信区间。

主审计没有一个“相关≥某值就证明有效”的成功阈值；相关性强弱、是否存在天花板、干预方向都由连续结果描述。LOSO不重新计算零模型，不输出LOSO的z/P/q；它的用途是成员影响，不是每个基因的显著性检验。

7. **跨疾病对照表**：按原稿Table 3的列（直接暴露药物数、未暴露药物数、未暴露药物进入前25%的数量、未暴露药物最高百分位、rho(L_count, C)），并列ACC、乳腺癌和黑色素瘤，分108药和124药两个集合，四种归一化全部列出。ACC和乳腺癌在124药集合及另外三种归一化下的数值由第5项补算，不属于本方案的黑色素瘤输出。

## 5. 随机背景与多重检验

### 5.1 设计

每主臂/恢复臂各10,000套度匹配随机种子；由5个独立RNG流各产生2,000套，基础随机种子`2026101801`至`2026101805`。每流用NumPy SeedSequence([基础种子, 臂索引])初始化default_rng，臂索引M0=0、M1=1。五流用于Monte Carlo稳定性检查，不是5组独立患者或模型训练重复。

沿用全图log2(degree+1)分位箱匹配；请求10箱，边界重复时合并。如候选不足，按10→9→…→1固定顺序选择第一个所有箱可抽足的方案；记录实际边界和箱数。仍不足则停，不跨箱静默补抽。同一套内无放回，排除当前臂真实种子，保留每个对应种子的原权重。M0不额外从随机候选池删除BRAF/MAP2K1/2，以保持“同度随机基因”的明确零假设；这与观察臂的防循环限制不同，须在解释中说明。**已核对这与乳腺癌对照的实现一致**：`analysis/method_strengthening.py`中的`generate_degree_matched_seed_sets`只把当臂真实种子排除出候选池，乳腺癌没有把CDK4/CDK6排除出候选池。因此两种疾病的零模型口径相同。各臂重新生成候选池，不复用不适用的旧ACC/Breast draws。

四变体在同一臂共用相同随机种子集合；每次重新传播、399基因归一化、背景μ_v、124药评分和百分位。保存float64尾部比较，避免float32改变近并列的超越计数。

### 5.2 检验家族

| 家族 | 范围与处理 | 解释 |
|---|---|---|
| F1 RPPA | 每个队列/模型情景的198个特征，BH q<0.01；无效P=1占位 | 筛种子用；特征级而非基因级FDR，情景间不是一次整体校正 |
| F2 药物 | 每臂每归一化124项上尾经验P，分别BH；主要家族M0×column_minmax | 探索性定位；附全部主/恢复臂×四变体合并BH作为跨分支敏感性（两臂均有则992项），不择一显著性口径 |
| F3 六药机制组 | M0四变体各一个组均值上尾P，四项BH | 次要预定义机制检查；六药不是六个独立临床试验 |
| 描述分析 | rho、Top20、LOSO、参数/队列/权重敏感性 | 不生成常规P值，不由多个尝试中筛显著结论 |
| H5/H6判据 | 情形顺序预测；M1−M0的Δz规则 | 按第4.2节的固定规则判定，不新增P值，不进入F2/F3的BH家族 |

经验P=(超越或等于观测次数+1)/(B+1)；z=(观测百分位−零均值)/零标准差（ddof=1），零方差时NA并标记。输出超越次数和95%二项Clopper–Pearson Monte Carlo区间；b=0不称真实P=0，不把124/(B+1)称BH q的全局下界。BH后向累积min必须有金标准测试。该零模型不重新采样患者或重做RPPA种子筛选，P/q仅相对于指定的度匹配随机背景，不能解读为对全部发现流程或临床效力的整体错误率保证。

六药固定为Dabrafenib、Vemurafenib、Encorafenib、Trametinib、Cobimetinib、Binimetinib。机制选择依据[官方NCI说明](https://www.cancer.gov/types/skin/hp/melanoma-treatment-pdq)，不使用本轮排名筛选。单药网络排名不能代替临床联合治疗证据。

六药都在124药和108药集合中（第2.4节）。同类的Selumetinib也在网络中，但未获批用于黑色素瘤，因此预先排除出H4组；它的排名只作描述性报告，不另做检验。

H4的次要支持判据（v0.3写明各项所用的变体和集合，口径与乳腺癌代码`evaluate_success_criteria`一致）：①M0主归一化下组P < 0.05；②把四种归一化下的四个组P值做BH校正，**取主归一化对应的那个q < 0.05**，不要求四个q全部 < 0.05；③在124药集合、主归一化下，六药至少3个进Top25%（前31名），**其中BRAF抑制剂（Dabrafenib、Vemurafenib、Encorafenib）和MEK抑制剂（Trametinib、Cobimetinib、Binimetinib）至少各1个**；④观察组均值高于零均值的变体至少3/4。四项全部成立记为pass，成立2–3项记为partial_recovery，成立0–1项记为fail，与乳腺癌的状态标签相同；每项逐条报告。108药集合（前27名）按同一规则作为S1敏感性报告，不替代主判定。增加分类条件的理由：MEK三药两两Jaccard为0.73–0.80，三个MEK药一起进入前25%实际上只相当于一个独立单位。乳腺癌的要求是“3个药中至少2个”，比例不同，原因在于组的大小和内部依赖不同，这一点在正文中写明。逐条件报告；不满足称“未达到预定义机制恢复标准”，不自动宣称无效，更不调种子救结果。M1只显示靶点恢复影响，不能用于替M0通过这一判据。

## 6. 样本量依据与计算预算

这是固定公共队列的审计，没有新增招募或以研究结果决定停止收样。106/125是当前全部符合条件候选，不是已完成的功效保证。

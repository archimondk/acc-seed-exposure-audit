## 3. 预测

### H5 情形预测

c_黑 = 5/108 < c_乳腺 = 14/108，两者相差0.083（> 0.02）。按v0.3的区间规则，“c_黑 < c_乳腺”分支的预测为：

- rho(L_count, C_MEL) ≤ 0.5772974445641333
- u ≥ 13/94

**预先说明：这个预测在算术上已经注定成立。** 108药中只有5个药的L_count不为0，其余103个并列为0。在这种结构下，只要C_MEL没有大面积并列，无论它怎样排序，rho最多只能达到约0.364，必然低于0.577。原网络只有两对药物的关联集完全相同，C_MEL不会出现大面积并列。前27名里至少有22个未暴露药物，u至少为22/103 = 0.214，必然高于13/94 = 0.138；这一条是精确的，不需要任何假设。124药集合同样如此（rho最多约0.372，u至少为25/118）。

处理方式（不修改阶段A规则）：H5仍按冻结规则计算并报告判定，但判定旁边必须同时标注“ARITHMETICALLY_DETERMINED：覆盖度过低，预测在算术上必然成立，不构成经验证据”。正文和回复信中不得把这一判定当作支持种子暴露假说的证据，只能用来说明黑色素瘤落在低覆盖度一端。

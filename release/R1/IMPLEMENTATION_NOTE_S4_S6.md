## 2. S5 协变量调整的RPPA筛选

冻结文本（第1.3、2.2节）已规定：每个RPPA特征做OLS，`z ~ E/K组别 + AGE/10 + SEX + 部位代理 + 采集中心`，含截距，HC3标准误；BH家族198项；q < 0.01且|组别系数| ≥ 0.5入选；L = min(|系数|/2, 1)；突变组件不变；年龄或性别缺失的病例删除；每特征两组各≥ 50个有限值且≥ 50%；剩余自由度≥ 30且设计满秩；只去掉无观测水平或全零哑变量；仍不能识别则记not_estimable，P = 1占位。

冻结文本没有写到、在此固定的细节：

1. **采集中心字段**：`data_clinical_sample.txt`中的`TISSUE_SOURCE_SITE`（中心名称）。在主队列中年龄和性别都完整的患者（两组合计）里，样本数≥ 10的中心保留名称，其余与缺失合并为`other_or_unknown`。映射只算一次，不随特征改变。
2. **部位代理**：`TUMOR_TISSUE_SITE`按“|”拆分，恰含`Regional Lymph Node`、`Regional Cutaneous or Subcutaneous Tissue`、`Distant Metastasis`中的一个时取该类，否则为`other_or_ambiguous`。
3. **哑变量编码**：每个分类变量以字典序第一个水平为参照。组别系数不受参照选择影响。
4. **HC3的P值参考分布**：双侧正态近似（|系数/HC3标准误|对标准正态），与statsmodels等常用软件对稳健协方差的默认处理一致，用于BH和入选。另输出以剩余自由度为参数的t分布P值，仅作描述，**不用于入选**。
5. **50%门槛的分母**：年龄和性别完整后每组的患者数。
6. **杠杆值为1**（HC3分母为0）时，该特征记not_estimable。
7. 主规则仍只允许单一明确基因注释；同基因多个入选特征取L最大者，并列按特征名字典序。
8. 输出中调整后的效应命名为`rppa_abs_adjusted_coefficient`，与主分析的中位数差分开。

实现验证：用逐一删除观测重新拟合，验证HC3协方差恒等式 V_HC3 = Σ_i (β̂ − β̂₍₋ᵢ₎)(β̂ − β̂₍₋ᵢ₎)ᵀ；本地如装有statsmodels，另与其`cov_type="HC3"`结果逐项比对。

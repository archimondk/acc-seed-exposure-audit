## Main finding

Across all 19 records, strict-eligibility agreement was 18/19 (94.7%; Cohen's κ = 0.642), and strict-binary-label agreement was 18/19 (94.7%; κ = 0.642).
The only strict-label disagreement was B02 (cabozantinib), which Claude could not assess because no abstract or full text was included. It is an access-related missing rating, not a scientific contradiction.
After excluding only B02, strict eligibility and the strict binary label both agreed in 18/18 records (100.0%; κ = 1.000 for eligibility; 100.0%; κ = 1.000 for the binary label).

## Adjudication interpretation

- **B02 Cabozantinib:** supply the official abstract/full text and rerun the locked model classification for B02 before final traceability is reported.
- **B08 Carboplatin:** the protocol defines evidence transferred from a related drug/class as class extrapolation. Retaining the first review's `class_only`/`class_extrapolated` terminology is more internally consistent; strict exclusion is unchanged.
- **B11 Lenvatinib, B14 Temsirolimus and B19 Erlotinib:** use `regimen_effect` because every exposure occurred in a non-decomposable combination. This is a taxonomy refinement; strict exclusion is unchanged.
- **B15 Sirolimus:** use `class_extrapolated` because the source tested the related mTOR inhibitor everolimus but not sirolimus. Strict exclusion is unchanged.
- **B06 Gemcitabine and B16 Sunitinib:** the raters agree on the categorical labels and strict exclusion. Claude's notes identify reasonable interpretive cautions, but no label change is needed.
